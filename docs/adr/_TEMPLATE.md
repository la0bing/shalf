# <Decision>

## Status

`draft` → `active` when adopted. Never edit an `active` ADR to change the decision: write a new
ADR and set this one to `superseded`, with `related:` pointing at the replacement.

## Context

The forces at play — constraints, requirements, what made a decision necessary now. Written so it
still makes sense to someone who was not present.

## Decision

What was decided, stated plainly and in the active voice.

## Consequences

What becomes easier, what becomes harder, what is now locked in and what it would cost to reverse.
Include the bad consequences — an ADR listing only upsides is not a record, it is an advert.

## Alternatives considered

Each option and why it lost.
